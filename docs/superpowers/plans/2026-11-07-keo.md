# Kéo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Kéo version 1. It is one FastAPI process in one Docker container that searches YouTube Music and charts from a phone browser and downloads one song per tap with spotDL. A daily history check downloads songs played 3 or more times today when the Spotify match is close.

**Architecture:** A single Python package, `keo`, split into small modules. `config` reads the environment and `keo.toml`. `match` is pure name matching. `library` is the only SQLite writer. `spotdl_cmd` builds and runs the `spotdl` CLI, one process at a time. `catalog` wraps `ytmusicapi`. `jobs` is the one-thread download queue. `history` is the daily pull and its scheduler. `web` holds the server-rendered pages and the JSON API behind one token. Tests replace YouTube Music and spotDL with fakes.

**Tech Stack:** Python 3.11+ (Docker uses 3.12), FastAPI, Uvicorn, Jinja2, SQLite (`sqlite3`), `ytmusicapi`, `spotdl` (CLI in a subprocess), pytest, httpx, Docker Compose, ffmpeg, Deno.

**Spec:** `docs/superpowers/specs/2026-11-07-keo-design.md`

## Global Constraints

- One FastAPI process in one Docker container. No playback, no native app, no user accounts, no “download the whole chart.”
- One shared token from `KEO_TOKEN`. The JSON API accepts `Authorization: Bearer <KEO_TOKEN>` or the session cookie. Both checks use a constant-time compare.
- Session cookie: httpOnly, 30 days (`Max-Age=2592000`), set by posting the token to `/login`.
- A JSON API call with a missing or wrong token gets 401. A page without a session redirects to `/login`. A wrong token posted to `/login` gets 401. YouTube Music failure gets 502 with a short reason. An unknown job or review row gets 404.
- Environment: `KEO_TOKEN`, `KEO_MUSIC_DIR`, `KEO_DATA_DIR` (default `/data`), `KEO_YTM_AUTH`, `KEO_YTM_CLIENT_ID` and `KEO_YTM_CLIENT_SECRET` (only for an OAuth file), `KEO_CONFIG` (default `/config/keo.toml`; a missing file means every default).
- `keo.toml` defaults: `format = "mp3"`, `bitrate = "128k"`, `cookie_file = ""`, `audio = ["youtube-music"]`, `lyrics = ["genius", "azlyrics", "musixmatch"]`, `output_template = "{artists} - {title}.{output-ext}"`, `history_timezone = "Asia/Ho_Chi_Minh"`, `history_hour = 23`.
- Every spotDL download always gets: `download`, the Spotify URL, `--output` under `KEO_MUSIC_DIR`, `--archive` under `KEO_DATA_DIR`, `--overwrite skip`, `--detect-formats mp3 m4a opus ogg flac wav`, and `--threads 1`. An empty `cookie_file` leaves out `--cookie-file`.
- Kéo never loads a spotDL `config.json`. spotDL runs with `HOME` set to `KEO_DATA_DIR/spotdl-home`, which holds a `config.json` containing `{"load_config": false}`.
- Only one `spotdl` process runs at a time.
- A download is finished only when spotDL exits 0 **and** the Spotify URL is in the archive.
- Name matching: NFKC, casefold, drop a `(feat …)` / `[ft …]` group, drop a trailing `feat`/`ft` and the rest, drop punctuation, collapse whitespace. The titles must be equal. The artists must be equal, or the shorter one must appear as a whole word run inside the longer one.
- History qualifies at 3 or more plays labeled `Today` for the same `videoId` in one pull. `ytmusicapi` runs with language `en`.
- Automated tests never call YouTube or Spotify.
- `ytmusicapi/` and `spotify-downloader/` are reference clones. They are git-ignored, and Kéo installs both from PyPI.

```python
"""Load Kéo settings from the environment and keo.toml.

This module reads files and nothing else. Startup calls load_settings once and
exits on ConfigError, so every message names the setting to fix.
"""

from __future__ import annotations

import json
import tomllib
from collections.abc import Mapping
from dataclasses import dataclass, fields, replace
from pathlib import Path
from typing import Any
from zoneinfo import ZoneInfo, ZoneInfoNotFoundError

FORMATS = ("mp3", "m4a", "opus", "ogg", "flac", "wav")
BITRATES = (
    "auto", "disable", "8k", "16k", "24k", "32k", "40k", "48k", "64k", "80k", "96k",
    "112k", "128k", "160k", "192k", "224k", "256k", "320k",
    *(str(level) for level in range(10)),
)
AUDIO_PROVIDERS = ("youtube-music", "youtube", "soundcloud", "bandcamp", "piped")
LYRICS_PROVIDERS = ("genius", "musixmatch", "azlyrics", "synced")
ALBUM_TYPES = ("", "single", "album", "compilation")
RESTRICT = ("", "strict", "ascii", "none")

DEFAULT_TIMEZONE = "Asia/Ho_Chi_Minh"
DEFAULT_HOUR = 23


class ConfigError(Exception):
    """Kéo cannot start with these settings."""


@dataclass(frozen=True)
class SpotdlSettings:
    format: str = "mp3"
    bitrate: str = "128k"
    audio: tuple[str, ...] = ("youtube-music",)
    sponsor_block: bool = False
    ffmpeg_args: str = ""
    cookie_file: str = ""
    lyrics: tuple[str, ...] = ("genius", "azlyrics", "musixmatch")
    genius_access_token: str = ""
    generate_lrc: bool = False
    id3_separator: str = "/"
    skip_album_art: bool = False
    search_query: str = ""
    album_type: str = ""
    only_verified_results: bool = False
    dont_filter_results: bool = False
    skip_explicit: bool = False
    output_template: str = "{artists} - {title}.{output-ext}"
    restrict: str = ""
    max_filename_length: int = 0
    proxy: str = ""
    yt_dlp_args: str = ""
    preload: bool = False
    max_retries: int = 3
    client_id: str = ""
    client_secret: str = ""


@dataclass(frozen=True)
class Settings:
    token: str
    music_dir: Path
    data_dir: Path
    ytm_auth: Path
    ytm_client_id: str
    ytm_client_secret: str
    spotdl: SpotdlSettings
    history_timezone: str
    history_hour: int


_DEFAULT_SPOTDL = SpotdlSettings()
_SPOTDL_NAMES = tuple(field.name for field in fields(SpotdlSettings))
_ALLOWED = {*_SPOTDL_NAMES, "history_timezone", "history_hour"}


def load_settings(env: Mapping[str, str]) -> Settings:
    token = _require(env, "KEO_TOKEN")
    music_dir = Path(_require(env, "KEO_MUSIC_DIR"))
    if not music_dir.is_dir():
        raise ConfigError(f"KEO_MUSIC_DIR is not a folder: {music_dir}")
    ytm_auth = Path(_require(env, "KEO_YTM_AUTH"))
    if not ytm_auth.is_file():
        raise ConfigError(f"KEO_YTM_AUTH file not found: {ytm_auth}")
    client_id = env.get("KEO_YTM_CLIENT_ID", "").strip()
    client_secret = env.get("KEO_YTM_CLIENT_SECRET", "").strip()
    if _is_oauth(ytm_auth) and not (client_id and client_secret):
        raise ConfigError(
            "KEO_YTM_AUTH is an OAuth file, so KEO_YTM_CLIENT_ID and "
            "KEO_YTM_CLIENT_SECRET are required"
        )
    spotdl, timezone, hour = _load_file(Path(env.get("KEO_CONFIG", "/config/keo.toml")))
    return Settings(
        token=token,
        music_dir=music_dir,
        data_dir=Path(env.get("KEO_DATA_DIR", "/data")),
        ytm_auth=ytm_auth,
        ytm_client_id=client_id,
        ytm_client_secret=client_secret,
        spotdl=spotdl,
        history_timezone=timezone,
        history_hour=hour,
    )


def _require(env: Mapping[str, str], name: str) -> str:
    value = env.get(name, "").strip()
    if not value:
        raise ConfigError(f"{name} is not set")
    return value


def _is_oauth(path: Path) -> bool:
    try:
        data = json.loads(path.read_text(encoding="utf-8"))
    except (OSError, ValueError) as exc:
        raise ConfigError(f"KEO_YTM_AUTH is not valid JSON: {exc}") from exc
    return isinstance(data, dict) and "refresh_token" in data


def _load_file(path: Path) -> tuple[SpotdlSettings, str, int]:
    data: dict[str, Any] = {}
    if path.is_file():
        try:
            data = tomllib.loads(path.read_text(encoding="utf-8"))
        except tomllib.TOMLDecodeError as exc:
            raise ConfigError(f"keo.toml is invalid: {exc}") from exc
    unknown = sorted(set(data) - _ALLOWED)
    if unknown:
        raise ConfigError(f"keo.toml has an unknown setting: {unknown[0]}")

    spotdl = replace(
        _DEFAULT_SPOTDL,
        **{
            name: _coerce(name, data[name], getattr(_DEFAULT_SPOTDL, name))
            for name in _SPOTDL_NAMES
            if name in data
        },
    )
    _check_spotdl(spotdl)

    timezone = _coerce(
        "history_timezone", data.get("history_timezone", DEFAULT_TIMEZONE), DEFAULT_TIMEZONE
    )
    try:
        ZoneInfo(timezone)
    except (ZoneInfoNotFoundError, ValueError) as exc:
        raise ConfigError(
            f"keo.toml: history_timezone is not a known time zone: {timezone}"
        ) from exc
    hour = _coerce("history_hour", data.get("history_hour", DEFAULT_HOUR), DEFAULT_HOUR)
    if not 0 <= hour <= 23:
        raise ConfigError("keo.toml: history_hour must be between 0 and 23")
    return spotdl, timezone, hour


def _coerce(name: str, value: Any, default: Any) -> Any:
    if isinstance(default, bool):
        if not isinstance(value, bool):
            raise ConfigError(f"keo.toml: {name} must be true or false")
        return value
    if isinstance(default, int):
        if isinstance(value, bool) or not isinstance(value, int):
            raise ConfigError(f"keo.toml: {name} must be a whole number")
        return value
    if isinstance(default, tuple):
        if not isinstance(value, list) or not all(isinstance(item, str) for item in value):
            raise ConfigError(f"keo.toml: {name} must be a list of strings")
        return tuple(value)
    if not isinstance(value, str):
        raise ConfigError(f"keo.toml: {name} must be a string")
    return value


def _check_spotdl(settings: SpotdlSettings) -> None:
    _one_of("format", settings.format, FORMATS)
    _one_of("bitrate", settings.bitrate, BITRATES)
    _one_of("album_type", settings.album_type, ALBUM_TYPES)
    _one_of("restrict", settings.restrict, RESTRICT)
    _some_of("audio", settings.audio, AUDIO_PROVIDERS)
    _some_of("lyrics", settings.lyrics, LYRICS_PROVIDERS)
    if settings.generate_lrc and "synced" not in settings.lyrics:
        raise ConfigError('keo.toml: generate_lrc needs "synced" in lyrics')
    if settings.cookie_file and not Path(settings.cookie_file).is_file():
        raise ConfigError(f"keo.toml: cookie_file not found: {settings.cookie_file}")
    if settings.max_retries < 0:
        raise ConfigError("keo.toml: max_retries must be 0 or more")
    if settings.max_filename_length < 0:
        raise ConfigError("keo.toml: max_filename_length must be 0 or more")


def _one_of(name: str, value: str, choices: tuple[str, ...]) -> None:
    if value not in choices:
        shown = ", ".join(repr(choice) for choice in choices)
        raise ConfigError(f"keo.toml: {name} must be one of {shown}")


def _some_of(name: str, values: tuple[str, ...], choices: tuple[str, ...]) -> None:
    if not values or any(value not in choices for value in values):
        shown = ", ".join(repr(choice) for choice in choices)
        raise ConfigError(f"keo.toml: {name} must be a non-empty list from {shown}")
```

```python
"""Decide whether a YouTube Music song and a Spotify result are the same song."""

from __future__ import annotations

import re
import unicodedata
from typing import NamedTuple

_FEAT_GROUP = re.compile(r"[(\[]\s*(?:feat|ft)\b[^)\]]*[)\]]")
_FEAT_TAIL = re.compile(r"\s(?:feat|ft)\b.*$")


class Name(NamedTuple):
    artist: str
    title: str


def normalize(text: str) -> str:
    text = unicodedata.normalize("NFKC", text).casefold()
    text = _FEAT_GROUP.sub(" ", text)
    text = _FEAT_TAIL.sub("", text)
    text = "".join(ch for ch in text if ch.isalnum() or ch.isspace())
    return " ".join(text.split())


def is_close(heard: Name, candidate: Name) -> bool:
    return normalize(heard.title) == normalize(candidate.title) and _artists_close(
        normalize(heard.artist), normalize(candidate.artist)
    )


def _artists_close(left: str, right: str) -> bool:
    if not left or not right:
        return False
    shorter, longer = sorted((left, right), key=len)
    return f" {shorter} " in f" {longer} "
```

```python
"""Read spotDL's archive file: one Spotify track URL per line."""

from __future__ import annotations

from pathlib import Path


def track_id(url: str) -> str | None:
    if "/track/" not in url:
        return None
    return url.rsplit("/track/", 1)[1].split("?", 1)[0].strip("/") or None


def archive_ids(path: Path) -> set[str]:
    if not path.is_file():
        return set()
    lines = path.read_text(encoding="utf-8").splitlines()
    return {song_id for line in lines if (song_id := track_id(line.strip()))}
```

```python
"""SQLite store for owned songs, download jobs, the review list, and history pulls.

This is the only module that writes the database. One lock serializes access
because the web threads, the worker, and the scheduler share one connection.
"""

from __future__ import annotations

import sqlite3
import threading
from dataclasses import dataclass
from datetime import datetime, timezone
from pathlib import Path

from keo.archive import archive_ids
from keo.match import normalize
from keo.records import HistoryItem

SCHEMA = """
CREATE TABLE IF NOT EXISTS history_pulls (
    id INTEGER PRIMARY KEY,
    started_at TEXT NOT NULL,
    status TEXT NOT NULL CHECK (status IN ('ok', 'failed')),
    error TEXT
);
CREATE TABLE IF NOT EXISTS history_items (
    id INTEGER PRIMARY KEY,
    pull_id INTEGER NOT NULL REFERENCES history_pulls (id),
    video_id TEXT NOT NULL,
    artist TEXT NOT NULL,
    title TEXT NOT NULL,
    played_label TEXT NOT NULL
);
CREATE TABLE IF NOT EXISTS songs (
    id INTEGER PRIMARY KEY,
    video_id TEXT UNIQUE,
    artist_key TEXT NOT NULL,
    title_key TEXT NOT NULL,
    spotify_id TEXT UNIQUE,
    artist TEXT NOT NULL,
    title TEXT NOT NULL,
    UNIQUE (artist_key, title_key)
);
CREATE TABLE IF NOT EXISTS jobs (
    id INTEGER PRIMARY KEY,
    video_id TEXT NOT NULL,
    artist TEXT NOT NULL,
    title TEXT NOT NULL,
    spotify_url TEXT,
    spotify_id TEXT,
    status TEXT NOT NULL CHECK (status IN ('queued', 'running', 'succeeded', 'failed')),
    source TEXT NOT NULL CHECK (source IN ('manual', 'history', 'review')),
    error TEXT,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL
);
CREATE UNIQUE INDEX IF NOT EXISTS jobs_one_active
    ON jobs (video_id) WHERE status IN ('queued', 'running');
CREATE TABLE IF NOT EXISTS review (
    video_id TEXT PRIMARY KEY,
    heard_artist TEXT NOT NULL,
    heard_title TEXT NOT NULL,
    candidate_artist TEXT,
    candidate_title TEXT,
    spotify_url TEXT,
    spotify_id TEXT,
    reason TEXT NOT NULL CHECK (reason IN ('weak_match', 'no_metadata')),
    created_at TEXT NOT NULL
);
"""


@dataclass(frozen=True)
class Job:
    id: int
    video_id: str
    artist: str
    title: str
    spotify_url: str | None
    spotify_id: str | None
    status: str
    source: str
    error: str | None
    created_at: str
    updated_at: str


@dataclass(frozen=True)
class ReviewRow:
    video_id: str
    heard_artist: str
    heard_title: str
    candidate_artist: str | None
    candidate_title: str | None
    spotify_url: str | None
    spotify_id: str | None
    reason: str
    created_at: str


@dataclass(frozen=True)
class HeardCount:
    video_id: str
    artist: str
    title: str
    plays: int


def _now() -> str:
    return datetime.now(timezone.utc).isoformat(timespec="seconds")


class Library:
    def __init__(self, db_path: Path, archive_path: Path) -> None:
        self._archive_path = archive_path
        self._lock = threading.Lock()
        self._db = sqlite3.connect(db_path, check_same_thread=False)
        self._db.row_factory = sqlite3.Row
        self._db.execute("PRAGMA journal_mode = WAL")
        self._db.executescript(SCHEMA)

    # Owned songs

    def is_owned(self, video_id: str, artist: str, title: str) -> bool:
        with self._lock:
            row = self._db.execute(
                "SELECT 1 FROM songs WHERE video_id = ? OR (artist_key = ? AND title_key = ?)",
                (video_id, normalize(artist), normalize(title)),
            ).fetchone()
        return row is not None

    def is_owned_spotify(self, spotify_id: str) -> bool:
        with self._lock:
            row = self._db.execute(
                "SELECT 1 FROM songs WHERE spotify_id = ?", (spotify_id,)
            ).fetchone()
        return row is not None or spotify_id in archive_ids(self._archive_path)

    def mark_owned(self, video_id: str, artist: str, title: str, spotify_id: str | None) -> None:
        with self._lock, self._db:
            self._db.execute(
                "INSERT OR IGNORE INTO songs"
                " (video_id, artist_key, title_key, spotify_id, artist, title)"
                " VALUES (?, ?, ?, ?, ?, ?)",
                (video_id, normalize(artist), normalize(title), spotify_id, artist, title),
            )
            self._db.execute("DELETE FROM review WHERE video_id = ?", (video_id,))

    # Jobs

    def enqueue(
        self,
        video_id: str,
        artist: str,
        title: str,
        *,
        source: str,
        spotify_url: str | None = None,
        spotify_id: str | None = None,
    ) -> Job:
        now = _now()
        with self._lock, self._db:
            active = self._active(video_id)
            if active is not None:
                return active
            cursor = self._db.execute(
                "INSERT INTO jobs (video_id, artist, title, spotify_url, spotify_id,"
                " status, source, created_at, updated_at)"
                " VALUES (?, ?, ?, ?, ?, 'queued', ?, ?, ?)",
                (video_id, artist, title, spotify_url, spotify_id, source, now, now),
            )
            job = self._job(cursor.lastrowid)
        assert job is not None
        return job

    def claim_next(self) -> Job | None:
        with self._lock, self._db:
            row = self._db.execute(
                "SELECT id FROM jobs WHERE status = 'queued' ORDER BY id LIMIT 1"
            ).fetchone()
            if row is None:
                return None
            self._db.execute(
                "UPDATE jobs SET status = 'running', updated_at = ? WHERE id = ?",
                (_now(), row["id"]),
            )
            return self._job(row["id"])

    def set_candidate(self, job_id: int, spotify_url: str, spotify_id: str) -> None:
        with self._lock, self._db:
            self._db.execute(
                "UPDATE jobs SET spotify_url = ?, spotify_id = ?, updated_at = ? WHERE id = ?",
                (spotify_url, spotify_id, _now(), job_id),
            )

    def finish(self, job_id: int, *, ok: bool, error: str | None = None) -> None:
        with self._lock, self._db:
            self._db.execute(
                "UPDATE jobs SET status = ?, error = ?, updated_at = ? WHERE id = ?",
                ("succeeded" if ok else "failed", error, _now(), job_id),
            )

    def get_job(self, job_id: int) -> Job | None:
        with self._lock:
            return self._job(job_id)

    def list_jobs(self, limit: int = 100) -> list[Job]:
        with self._lock:
            rows = self._db.execute(
                "SELECT * FROM jobs ORDER BY id DESC LIMIT ?", (limit,)
            ).fetchall()
        return [Job(**dict(row)) for row in rows]

    def active_job(self, video_id: str) -> Job | None:
        with self._lock:
            return self._active(video_id)

    def retry(self, job_id: int) -> Job | None:
        with self._lock, self._db:
            job = self._job(job_id)
            if job is None or job.status != "failed":
                return job
            active = self._active(job.video_id)
            if active is not None:
                return active
            self._db.execute(
                "UPDATE jobs SET status = 'queued', error = NULL, updated_at = ? WHERE id = ?",
                (_now(), job_id),
            )
            return self._job(job_id)

    def requeue_running(self) -> None:
        with self._lock, self._db:
            self._db.execute(
                "UPDATE jobs SET status = 'queued', updated_at = ? WHERE status = 'running'",
                (_now(),),
            )

    # Review list

    def add_review(
        self,
        video_id: str,
        heard_artist: str,
        heard_title: str,
        *,
        reason: str,
        candidate_artist: str | None = None,
        candidate_title: str | None = None,
        spotify_url: str | None = None,
        spotify_id: str | None = None,
        replace: bool = False,
    ) -> None:
        verb = "INSERT OR REPLACE" if replace else "INSERT OR IGNORE"
        with self._lock, self._db:
            self._db.execute(
                f"{verb} INTO review (video_id, heard_artist, heard_title, candidate_artist,"
                " candidate_title, spotify_url, spotify_id, reason, created_at)"
                " VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)",
                (
                    video_id, heard_artist, heard_title, candidate_artist, candidate_title,
                    spotify_url, spotify_id, reason, _now(),
                ),
            )

    def get_review(self, video_id: str) -> ReviewRow | None:
        with self._lock:
            row = self._db.execute(
                "SELECT * FROM review WHERE video_id = ?", (video_id,)
            ).fetchone()
        return ReviewRow(**dict(row)) if row else None

    def list_review(self) -> list[ReviewRow]:
        with self._lock:
            rows = self._db.execute("SELECT * FROM review ORDER BY created_at").fetchall()
        return [ReviewRow(**dict(row)) for row in rows]

    # History

    def record_pull(
        self, started_at: str, status: str, error: str | None, items: list[HistoryItem]
    ) -> int:
        with self._lock, self._db:
            cursor = self._db.execute(
                "INSERT INTO history_pulls (started_at, status, error) VALUES (?, ?, ?)",
                (started_at, status, error),
            )
            pull_id = cursor.lastrowid
            self._db.executemany(
                "INSERT INTO history_items (pull_id, video_id, artist, title, played_label)"
                " VALUES (?, ?, ?, ?, ?)",
                [
                    (pull_id, item.video_id, item.artist, item.title, item.played_label)
                    for item in items
                ],
            )
        assert pull_id is not None
        return pull_id

    def has_ok_pull_on(self, local_date: str) -> bool:
        with self._lock:
            row = self._db.execute(
                "SELECT 1 FROM history_pulls"
                " WHERE status = 'ok' AND substr(started_at, 1, 10) = ?",
                (local_date,),
            ).fetchone()
        return row is not None

    def count_today(self, pull_id: int) -> list[HeardCount]:
        with self._lock:
            rows = self._db.execute(
                "SELECT video_id, artist, title, COUNT(*) AS plays FROM history_items"
                " WHERE pull_id = ? AND played_label = 'Today'"
                " GROUP BY video_id ORDER BY MIN(id)",
                (pull_id,),
            ).fetchall()
        return [HeardCount(**dict(row)) for row in rows]

    # Helpers that expect the lock to be held

    def _job(self, job_id: int | None) -> Job | None:
        row = self._db.execute("SELECT * FROM jobs WHERE id = ?", (job_id,)).fetchone()
        return Job(**dict(row)) if row else None

    def _active(self, video_id: str) -> Job | None:
        row = self._db.execute(
            "SELECT * FROM jobs WHERE video_id = ? AND status IN ('queued', 'running')",
            (video_id,),
        ).fetchone()
        return Job(**dict(row)) if row else None
```

```python
"""Build and run spotDL commands. Only one spotDL process runs at a time.

spotDL exits 0 even when the one song fails, so a download counts as finished
only when the Spotify URL also landed in the archive file.
"""

from __future__ import annotations

import json
import os
import subprocess
import threading
from collections.abc import Callable
from dataclasses import dataclass
from pathlib import Path
from typing import Any, Literal

from keo.archive import archive_ids, track_id
from keo.config import FORMATS, SpotdlSettings

Operation = Literal["save", "download"]
Runner = Callable[..., subprocess.CompletedProcess]

SAVE_TIMEOUT_SECONDS = 300
DOWNLOAD_TIMEOUT_SECONDS = 1800
TAIL_LINES = 40


@dataclass(frozen=True)
class Paths:
    music_dir: Path
    data_dir: Path

    @property
    def archive(self) -> Path:
        return self.data_dir / "archive.txt"

    @property
    def home(self) -> Path:
        return self.data_dir / "spotdl-home"


@dataclass(frozen=True)
class Candidate:
    name: str
    artist: str
    artists: tuple[str, ...]
    url: str
    song_id: str

    @property
    def primary_artist(self) -> str:
        return self.artists[0] if self.artists else self.artist


@dataclass(frozen=True)
class Lookup:
    candidate: Candidate | None
    output: str


@dataclass(frozen=True)
class DownloadResult:
    ok: bool
    output: str


def build_args(
    settings: SpotdlSettings, paths: Paths, operation: Operation, query: str
) -> list[str]:
    s = settings
    args = [operation, query]
    if operation == "save":
        args += ["--save-file", "-"]
        _flag(args, "--preload", s.preload)
    else:
        args += [
            "--output", str(paths.music_dir / s.output_template),
            "--archive", str(paths.archive),
            "--overwrite", "skip",
            "--detect-formats", *FORMATS,
            "--format", s.format,
            "--bitrate", s.bitrate,
            "--id3-separator", s.id3_separator,
        ]
        _flag(args, "--sponsor-block", s.sponsor_block)
        _value(args, "--ffmpeg-args", s.ffmpeg_args)
        _flag(args, "--generate-lrc", s.generate_lrc)
        _flag(args, "--skip-album-art", s.skip_album_art)
        _flag(args, "--skip-explicit", s.skip_explicit)
        _value(args, "--restrict", s.restrict)
        if s.max_filename_length:
            args += ["--max-filename-length", str(s.max_filename_length)]
        _value(args, "--yt-dlp-args", s.yt_dlp_args)
    args += [
        "--threads", "1",
        "--max-retries", str(s.max_retries),
        "--audio", *s.audio,
        "--lyrics", *s.lyrics,
    ]
    _value(args, "--genius-access-token", s.genius_access_token)
    _value(args, "--search-query", s.search_query)
    _value(args, "--album-type", s.album_type)
    _flag(args, "--only-verified-results", s.only_verified_results)
    _flag(args, "--dont-filter-results", s.dont_filter_results)
    _value(args, "--proxy", s.proxy)
    _value(args, "--client-id", s.client_id)
    _value(args, "--client-secret", s.client_secret)
    _value(args, "--cookie-file", s.cookie_file)
    return args


def parse_save_output(stdout: str) -> Candidate | None:
    decoder = json.JSONDecoder()
    start = stdout.find("[")
    while start != -1:
        try:
            value, _ = decoder.raw_decode(stdout, start)
        except json.JSONDecodeError:
            value = None
        if isinstance(value, list) and (not value or isinstance(value[0], dict)):
            return _candidate(value[0]) if value else None
        start = stdout.find("[", start + 1)
    return None


def tail(text: str, lines: int = TAIL_LINES) -> str:
    return "\n".join(text.strip().splitlines()[-lines:])


class Spotdl:
    def __init__(
        self,
        settings: SpotdlSettings,
        paths: Paths,
        binary: str = "spotdl",
        runner: Runner = subprocess.run,
    ) -> None:
        self._settings = settings
        self._paths = paths
        self._binary = binary
        self._runner = runner
        self._lock = threading.Lock()

    def lookup(self, query: str) -> Lookup:
        proc = self._run("save", query, SAVE_TIMEOUT_SECONDS)
        if proc is None:
            return Lookup(None, "spotDL lookup timed out")
        candidate = parse_save_output(proc.stdout) if proc.returncode == 0 else None
        return Lookup(candidate, tail(f"{proc.stdout}\n{proc.stderr}"))

    def download(self, url: str, spotify_id: str | None) -> DownloadResult:
        proc = self._run("download", url, DOWNLOAD_TIMEOUT_SECONDS)
        if proc is None:
            return DownloadResult(False, "spotDL download timed out")
        song_id = spotify_id or track_id(url)
        finished = proc.returncode == 0 and song_id in archive_ids(self._paths.archive)
        return DownloadResult(finished, tail(f"{proc.stdout}\n{proc.stderr}"))

    def _run(
        self, operation: Operation, query: str, timeout: int
    ) -> subprocess.CompletedProcess | None:
        args = [self._binary, *build_args(self._settings, self._paths, operation, query)]
        with self._lock:
            _prepare_home(self._paths.home)
            try:
                return self._runner(
                    args,
                    capture_output=True,
                    text=True,
                    timeout=timeout,
                    env={**os.environ, "HOME": str(self._paths.home)},
                    check=False,
                )
            except subprocess.TimeoutExpired:
                return None


def _prepare_home(home: Path) -> None:
    for folder in (home / ".config" / "spotdl", home / ".spotdl"):
        folder.mkdir(parents=True, exist_ok=True)
        (folder / "config.json").write_text('{"load_config": false}\n', encoding="utf-8")


def _candidate(data: dict[str, Any]) -> Candidate | None:
    url, song_id = data.get("url"), data.get("song_id")
    if not url or not song_id:
        return None
    artists = tuple(a for a in data.get("artists") or [] if isinstance(a, str))
    return Candidate(
        name=data.get("name") or "",
        artist=data.get("artist") or "",
        artists=artists,
        url=url,
        song_id=song_id,
    )


def _flag(args: list[str], flag: str, enabled: bool) -> None:
    if enabled:
        args.append(flag)


def _value(args: list[str], flag: str, value: str) -> None:
    if value:
        args += [flag, value]
```

```python
"""YouTube Music lookups through ytmusicapi, returned as plain records."""

from __future__ import annotations

import json
from collections.abc import Callable, Iterable
from pathlib import Path
from typing import Any, TypeVar

from ytmusicapi import OAuthCredentials, YTMusic

from keo.records import HistoryItem, MoodRef, PlaylistRef, SongRow

T = TypeVar("T")
CHART_CAROUSELS = ("daily", "weekly", "videos")


class CatalogError(Exception):
    """YouTube Music failed or rejected the request."""


def open_ytmusic(auth_path: Path, client_id: str, client_secret: str) -> YTMusic:
    auth = json.loads(auth_path.read_text(encoding="utf-8"))
    if "refresh_token" in auth:
        credentials = OAuthCredentials(client_id=client_id, client_secret=client_secret)
        return YTMusic(str(auth_path), language="en", oauth_credentials=credentials)
    return YTMusic(str(auth_path), language="en")


class Catalog:
    def __init__(self, ytm: Any) -> None:
        self._ytm = ytm

    def search(self, query: str) -> list[SongRow]:
        return _songs(self._call(self._ytm.search, query, filter="songs", limit=20))

    def suggestions(self, query: str) -> list[str]:
        return list(self._call(self._ytm.get_search_suggestions, query))

    def charts(self) -> list[PlaylistRef]:
        data = self._call(self._ytm.get_charts, "VN")
        return [
            PlaylistRef(item["playlistId"], item.get("title") or "")
            for key in CHART_CAROUSELS
            for item in data.get(key) or []
            if item.get("playlistId")
        ]

    def moods(self) -> dict[str, list[MoodRef]]:
        data = self._call(self._ytm.get_mood_categories)
        return {
            section: [MoodRef(item["params"], item["title"]) for item in items]
            for section, items in data.items()
        }

    def mood_playlists(self, params: str) -> list[PlaylistRef]:
        return [
            PlaylistRef(item["playlistId"], item.get("title") or "")
            for item in self._call(self._ytm.get_mood_playlists, params)
            if item.get("playlistId")
        ]

    def playlist(self, playlist_id: str) -> tuple[str, list[SongRow]]:
        data = self._call(self._ytm.get_playlist, playlist_id, limit=100)
        return data.get("title") or "", _songs(data.get("tracks") or [])

    def radio(self, video_id: str) -> list[SongRow]:
        data = self._call(self._ytm.get_watch_playlist, videoId=video_id, limit=25)
        return _songs(data.get("tracks") or [])

    def history(self) -> list[HistoryItem]:
        items = []
        for item in self._call(self._ytm.get_history):
            song = _song(item)
            if song is not None:
                items.append(
                    HistoryItem(song.video_id, song.primary_artist, song.title, item.get("played") or "")
                )
        return items

    def _call(self, fn: Callable[..., T], *args: Any, **kwargs: Any) -> T:
        try:
            return fn(*args, **kwargs)
        except Exception as exc:
            raise CatalogError(f"YouTube Music request failed: {exc}") from exc


def _song(item: dict[str, Any]) -> SongRow | None:
    video_id = item.get("videoId")
    if not video_id:
        return None
    artists = tuple(a["name"] for a in item.get("artists") or [] if a.get("name"))
    album = item.get("album")
    return SongRow(
        video_id=video_id,
        title=item.get("title") or "",
        artists=artists,
        album=album.get("name") if isinstance(album, dict) else None,
    )


def _songs(items: Iterable[dict[str, Any]]) -> list[SongRow]:
```

```python
"""The download queue. One worker thread runs one job at a time."""

from __future__ import annotations

import logging
import threading

from keo.library import Job, Library
from keo.spotdl_cmd import Spotdl

log = logging.getLogger(__name__)
IDLE_WAIT_SECONDS = 5


class Worker:
    def __init__(self, library: Library, spotdl: Spotdl) -> None:
        self._library = library
        self._spotdl = spotdl
        self._wake = threading.Event()
        self._stop = threading.Event()
        self._thread: threading.Thread | None = None

    def submit(
        self,
        video_id: str,
        artist: str,
        title: str,
        *,
        source: str = "manual",
        spotify_url: str | None = None,
        spotify_id: str | None = None,
    ) -> Job | None:
        """Queue one download. Returns None when the song is already owned."""
        if self._library.is_owned(video_id, artist, title):
            return None
        job = self._library.enqueue(
            video_id, artist, title, source=source, spotify_url=spotify_url, spotify_id=spotify_id
        )
        self._wake.set()
        return job

    def retry(self, job_id: int) -> Job | None:
        job = self._library.retry(job_id)
        self._wake.set()
        return job

    def run_once(self) -> bool:
        job = self._library.claim_next()
        if job is None:
            return False
        try:
            self._process(job)
        except Exception as exc:
            log.exception("Job %s crashed", job.id)
            self._library.finish(job.id, ok=False, error=f"Kéo error: {exc}")
        return True

    def start(self) -> None:
        self._thread = threading.Thread(target=self._loop, name="keo-worker", daemon=True)
        self._thread.start()

    def stop(self) -> None:
        self._stop.set()
        self._wake.set()
        if self._thread is not None:
            self._thread.join(timeout=5)

    def _loop(self) -> None:
        while not self._stop.is_set():
            if not self.run_once():
                self._wake.wait(timeout=IDLE_WAIT_SECONDS)
                self._wake.clear()

    def _process(self, job: Job) -> None:
        url, spotify_id = job.spotify_url, job.spotify_id
        if url is None:
            lookup = self._spotdl.lookup(f"{job.artist} - {job.title}")
            if lookup.candidate is None:
                self._library.finish(
                    job.id,
                    ok=False,
                    error=f"No Spotify metadata for {job.artist} - {job.title}\n{lookup.output}",
                )
                return
            url, spotify_id = lookup.candidate.url, lookup.candidate.song_id
            self._library.set_candidate(job.id, url, spotify_id)

        if spotify_id and self._library.is_owned_spotify(spotify_id):
            self._library.mark_owned(job.video_id, job.artist, job.title, spotify_id)
            self._library.finish(job.id, ok=True)
            return

        result = self._spotdl.download(url, spotify_id)
        if result.ok:
            self._library.mark_owned(job.video_id, job.artist, job.title, spotify_id)
            self._library.finish(job.id, ok=True)
        else:
            self._library.finish(job.id, ok=False, error=result.output)
```

```python
"""The shared-token check for the JSON API and the browser session cookie."""

from __future__ import annotations

import hashlib
import hmac

from fastapi import Request

COOKIE_NAME = "keo_session"
COOKIE_MAX_AGE = 30 * 24 * 60 * 60


def session_value(token: str) -> str:
    return hmac.new(token.encode(), b"keo-session", hashlib.sha256).hexdigest()


def is_authorized(request: Request, token: str) -> bool:
    header = request.headers.get("authorization", "")
    if header.startswith("Bearer ") and hmac.compare_digest(
        header.removeprefix("Bearer ").encode(), token.encode()
    ):
        return True
    cookie = request.cookies.get(COOKIE_NAME, "")
    return bool(cookie) and hmac.compare_digest(cookie.encode(), session_value(token).encode())
```

```python
from typing import Annotated

from fastapi import APIRouter, Form, Request
from fastapi.responses import HTMLResponse, RedirectResponse

from keo.web.auth import COOKIE_MAX_AGE, COOKIE_NAME, session_value
from keo.web.deps import TEMPLATES, get_services

router = APIRouter()


@router.get("/login", response_class=HTMLResponse)
def login_page(request: Request):
    return TEMPLATES.TemplateResponse(request, "login.html", {"error": None})


@router.post("/login")
def login(request: Request, token: Annotated[str, Form()] = ""):
    expected = get_services(request).token
    if not hmac.compare_digest(token.encode(), expected.encode()):
        return TEMPLATES.TemplateResponse(
            request, "login.html", {"error": "Wrong token."}, status_code=401
        )
    response = RedirectResponse("/", status_code=303)
    response.set_cookie(
        COOKIE_NAME,
        session_value(expected),
        max_age=COOKIE_MAX_AGE,
        httponly=True,
        samesite="lax",
    )
    return response
```

```python
from fastapi import APIRouter, Depends, Request
from pydantic import BaseModel

from keo.library import Job
from keo.web.deps import get_services, require_api

router = APIRouter()


class DownloadRequest(BaseModel):
    video_id: str
    title: str
    artists: list[str]


def queued(job: Job | None) -> dict:
    return {"owned": job is None, "job": asdict(job) if job else None}


@router.post("/api/downloads", dependencies=[Depends(require_api)])
```

```python
"""The FastAPI app: phone pages and the JSON API behind one token."""

from __future__ import annotations

from pathlib import Path
from typing import Any

from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse, RedirectResponse
from fastapi.staticfiles import StaticFiles

from keo.catalog import CatalogError
from keo.web.deps import TEMPLATES, LoginRequired, Services
from keo.web.routes_login import router as login_router
from keo.web.routes_queue import router as queue_router
from keo.web.routes_search import router as search_router

STATIC_DIR = Path(__file__).parent / "static"


def create_app(services: Services, lifespan: Any = None) -> FastAPI:
    app = FastAPI(title="Kéo", lifespan=lifespan)
    app.state.services = services
    app.mount("/static", StaticFiles(directory=STATIC_DIR), name="static")
    for router in (login_router, search_router, queue_router):
        app.include_router(router)

    @app.exception_handler(LoginRequired)
    async def login_required(request: Request, exc: LoginRequired):
        return RedirectResponse("/login", status_code=303)

    @app.exception_handler(CatalogError)
    async def catalog_failed(request: Request, exc: CatalogError):
        reason = str(exc)[:300]
        if request.url.path.startswith("/api/"):
            return JSONResponse({"detail": reason}, status_code=502)
        return TEMPLATES.TemplateResponse(
            request, "error.html", {"message": reason}, status_code=502
        )

    return app
```

```python
"""Start Kéo: read settings, open the library, and serve the app.

Run with: uvicorn --factory keo.main:build_app
"""

from __future__ import annotations

import logging
import os
import sys
from contextlib import asynccontextmanager

from fastapi import FastAPI

from keo.catalog import Catalog, open_ytmusic
from keo.config import ConfigError, load_settings
from keo.jobs import Worker
from keo.library import Library
from keo.spotdl_cmd import Paths, Spotdl
from keo.web import Services, create_app


def build_app() -> FastAPI:
    logging.basicConfig(level=logging.INFO)
    try:
        settings = load_settings(os.environ)
    except ConfigError as exc:
        sys.exit(f"Kéo cannot start: {exc}")
    settings.data_dir.mkdir(parents=True, exist_ok=True)
    paths = Paths(settings.music_dir, settings.data_dir)
    library = Library(settings.data_dir / "keo.db", paths.archive)
    library.requeue_running()
    spotdl = Spotdl(settings.spotdl, paths)
    worker = Worker(library, spotdl)
    try:
        ytm = open_ytmusic(settings.ytm_auth, settings.ytm_client_id, settings.ytm_client_secret)
    except Exception as exc:
        sys.exit(f"Kéo cannot start: KEO_YTM_AUTH could not be loaded: {exc}")
    services = Services(
        token=settings.token,
        catalog=Catalog(ytm),
        library=library,
        worker=worker,
        spotdl=spotdl,
    )

    @asynccontextmanager
    async def lifespan(app: FastAPI):
        worker.start()
        yield
        worker.stop()

    return create_app(services, lifespan=lifespan)
```

```javascript
document.addEventListener("click", async (event) => {
  const button = event.target.closest("button[data-download], button[data-post]");
  if (!button) return;
  button.disabled = true;
  const body = button.dataset.download || null;
  try {
    const response = await fetch(button.dataset.post || "/api/downloads", {
      method: "POST",
      headers: body ? { "Content-Type": "application/json" } : {},
      body,
      credentials: "same-origin",
    });
    const data = await response.json();
    button.textContent = response.ok ? label(data) : data.detail || "Failed";
  } catch {
    button.textContent = "Failed";
    button.disabled = false;
  }
});

function label(data) {
  if (data.owned) return "In library";
  if (data.job) return data.job.status === "queued" ? "Queued" : data.job.status;
  if (data.status === "checking") return "Checking…";
  return "Done";
}

const search = document.querySelector("input[list=suggestions]");
if (search) {
  search.addEventListener("input", async () => {
    if (search.value.trim().length < 2) return;
    const response = await fetch(
      `/api/suggestions?q=${encodeURIComponent(search.value)}`,
      { credentials: "same-origin" },
    );
    if (!response.ok) return;
    const options = (await response.json()).map((text) =>
      Object.assign(document.createElement("option"), { value: text }),
    );
    document.getElementById("suggestions").replaceChildren(...options);
  });
}
```

```python
"""The daily YouTube Music history check.

A song played 3 or more times today downloads on its own only when the Spotify
match is close. Anything else waits on the review list for a tap.
"""

from __future__ import annotations

import logging
import threading
from collections.abc import Callable
from datetime import date, datetime
from zoneinfo import ZoneInfo

from keo.catalog import Catalog, CatalogError
from keo.jobs import Worker
from keo.library import Library
from keo.match import Name, is_close
from keo.spotdl_cmd import Spotdl

log = logging.getLogger(__name__)

PLAYS_TO_QUALIFY = 3
CHECK_EVERY_SECONDS = 60


def decide(
    video_id: str,
    artist: str,
    title: str,
    *,
    library: Library,
    worker: Worker,
    spotdl: Spotdl,
    source: str = "history",
    replace_review: bool = False,
) -> str:
    candidate = spotdl.lookup(f"{artist} - {title}").candidate
    if candidate is None:
        library.add_review(video_id, artist, title, reason="no_metadata", replace=replace_review)
        return "review"
    if library.is_owned_spotify(candidate.song_id):
        library.mark_owned(video_id, artist, title, candidate.song_id)
        return "owned"
    if is_close(Name(artist, title), Name(candidate.primary_artist, candidate.name)):
        worker.submit(
            video_id, artist, title,
            source=source, spotify_url=candidate.url, spotify_id=candidate.song_id,
        )
        return "queued"
    library.add_review(
        video_id, artist, title,
        reason="weak_match",
        candidate_artist=candidate.primary_artist,
        candidate_title=candidate.name,
        spotify_url=candidate.url,
        spotify_id=candidate.song_id,
        replace=replace_review,
    )
    return "review"


def run_pull(
    *, catalog: Catalog, library: Library, worker: Worker, spotdl: Spotdl, now: datetime
) -> int | None:
    started_at = now.isoformat(timespec="seconds")
    try:
        items = catalog.history()
    except CatalogError as exc:
        log.warning("History pull failed: %s", exc)
        library.record_pull(started_at, "failed", str(exc), [])
        return None
    pull_id = library.record_pull(started_at, "ok", None, items)
    for heard in library.count_today(pull_id):
        if heard.plays < PLAYS_TO_QUALIFY:
            continue
        if library.is_owned(heard.video_id, heard.artist, heard.title):
            continue
        if library.active_job(heard.video_id) is not None:
            continue
        try:
            decide(
                heard.video_id, heard.artist, heard.title,
                library=library, worker=worker, spotdl=spotdl,
            )
        except Exception:
            log.exception("History decision failed for %s", heard.video_id)
    return pull_id


def is_due(now: datetime, hour: int, library: Library, last_attempt: date | None) -> bool:
    today = now.date()
    return (
        now.hour >= hour
        and last_attempt != today
        and not library.has_ok_pull_on(today.isoformat())
    )


class Scheduler:
    def __init__(
        self,
        *,
        catalog: Catalog,
        library: Library,
        worker: Worker,
        spotdl: Spotdl,
        timezone: str,
        hour: int,
        clock: Callable[[], datetime] | None = None,
    ) -> None:
        zone = ZoneInfo(timezone)
        self._catalog = catalog
        self._library = library
        self._worker = worker
        self._spotdl = spotdl
        self._hour = hour
        self._clock = clock or (lambda: datetime.now(zone))
        self._last_attempt: date | None = None
        self._stop = threading.Event()
        self._thread: threading.Thread | None = None

    def tick(self) -> bool:
        now = self._clock()
        if not is_due(now, self._hour, self._library, self._last_attempt):
            return False
        self._last_attempt = now.date()
        run_pull(
            catalog=self._catalog, library=self._library,
            worker=self._worker, spotdl=self._spotdl, now=now,
        )
        return True

    def start(self) -> None:
        self._thread = threading.Thread(target=self._loop, name="keo-history", daemon=True)
        self._thread.start()

    def stop(self) -> None:
        self._stop.set()
        if self._thread is not None:
            self._thread.join(timeout=5)

    def _loop(self) -> None:
        while not self._stop.is_set():
            try:
                self.tick()
            except Exception:
                log.exception("History check crashed")
            self._stop.wait(CHECK_EVERY_SECONDS)
```

```python
"""Start downloads, work the review list, and watch jobs."""

from __future__ import annotations

from dataclasses import asdict

from fastapi import APIRouter, Depends, HTTPException, Request
from fastapi.responses import HTMLResponse, JSONResponse
from pydantic import BaseModel

from keo.history import decide
from keo.library import Job
from keo.web.deps import TEMPLATES, get_services, require_api, require_page

router = APIRouter()
PAGE = {"response_class": HTMLResponse, "dependencies": [Depends(require_page)]}
API = {"dependencies": [Depends(require_api)]}


class DownloadRequest(BaseModel):
    video_id: str
    title: str
    artists: list[str]


def queued(job: Job | None) -> dict:
    return {"owned": job is None, "job": asdict(job) if job else None}


@router.post("/api/downloads", **API)
def api_download(request: Request, body: DownloadRequest):
    artist = body.artists[0] if body.artists else ""
    return queued(get_services(request).worker.submit(body.video_id, artist, body.title))


@router.get("/review", **PAGE)
def review_page(request: Request):
    rows = get_services(request).library.list_review()
    return TEMPLATES.TemplateResponse(request, "review.html", {"rows": rows})


@router.get("/api/review", **API)
def api_review(request: Request):
    return [asdict(row) for row in get_services(request).library.list_review()]


@router.post("/api/review/{video_id}/download", **API)
def api_review_download(request: Request, video_id: str):
    services = get_services(request)
    row = services.library.get_review(video_id)
    if row is None:
        raise HTTPException(status_code=404, detail="Not on the review list")
    if row.spotify_url:
        job = services.worker.submit(
            row.video_id, row.heard_artist, row.heard_title,
            source="review", spotify_url=row.spotify_url, spotify_id=row.spotify_id,
        )
        return queued(job)
    services.run_later(
        lambda: decide(
            row.video_id, row.heard_artist, row.heard_title,
            library=services.library, worker=services.worker, spotdl=services.spotdl,
            source="review", replace_review=True,
        )
    )
    return JSONResponse({"status": "checking"}, status_code=202)


@router.get("/jobs", **PAGE)
def jobs_page(request: Request):
    jobs = get_services(request).library.list_jobs()
    return TEMPLATES.TemplateResponse(request, "jobs.html", {"jobs": jobs})


@router.get("/api/jobs", **API)
def api_jobs(request: Request):
    return [asdict(job) for job in get_services(request).library.list_jobs()]


@router.post("/api/jobs/{job_id}/retry", **API)
def api_retry(request: Request, job_id: int):
    job = get_services(request).worker.retry(job_id)
    if job is None:
        raise HTTPException(status_code=404, detail="Unknown job")
    return queued(job)
```

```bash
TOKEN=$(grep ^KEO_TOKEN= .env | cut -d= -f2)
curl -s -o /dev/null -w "%{http_code}\n" "http://localhost:8000/api/search?q=lac%20troi"
curl -s -H "Authorization: Bearer $TOKEN" "http://localhost:8000/api/search?q=lac%20troi" | head -c 300; echo
curl -s -H "Authorization: Bearer $TOKEN" "http://localhost:8000/api/charts" | head -c 300; echo
```

Expected: `401`, then a JSON list of songs, then a JSON list of Vietnam chart playlists.

On the phone, sign in, search for a song, and tap Download. Then:
- Open Jobs. The job goes from `queued` or `running` to `succeeded`, and a file appears in the music folder.
- Tap Download again on the same song. The button says “In library”, and no second job appears.
- Open Charts, a chart playlist, Moods, and Radio on one song. Each lists songs with Download buttons.
- For the history check, set `history_hour` in `keo.toml` to the current hour, play one song 3 times on YouTube Music, and run `docker compose restart keo`. Within a minute the logs show the pull. Jobs shows a `history` job when the match is close. Review shows the song when it is not.
- Delete the song's file and its archive line to retry, or pick a song spotDL cannot find. A failed job shows the spotDL output and a Retry button.

Set `history_hour` back to `23` and restart when done.
